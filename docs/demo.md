# Demo checklist

A short run-through for showing Spectr live. It takes about two minutes.

## Before you start

- The Mac is awake, unlocked and sharing its screen (the menu bar icon shows it is live).
- The Mac has a steady connection. The stream uses up to 8 Mbps of upload; use a phone hotspot if the venue Wi-Fi is weak.
- Close any tabs or windows you would not want on a shared screen.
- Make one test call and say the exact tasks you plan to use.

## The run

1. Call the Mac on FaceTime. Its screen appears on the call.
2. Ask for something with a visible result, such as "open Notes and write milk".
3. Correct it while it works: "actually, write eggs". The Mac changes course.
4. Hang up. The task stops with the call.
5. Open the iPhone app to show the same screen live, if there is time.

## If something goes wrong

- **No screen on the call:** check that the Mac is sharing, then call again.
- **The voice lags:** hang up and call again; the next call starts on a fresh room.
- **The task runs on the wrong machine:** make sure the Mac has been online for a minute, so it is chosen over the hosted browser.
